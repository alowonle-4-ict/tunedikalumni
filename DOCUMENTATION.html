1. System Overview

TUNEDIK Alumni Management System is a web-based platform that manages the full lifecycle of alumni membership — from registration and payment, through community engagement, to elections and financial reporting.

It is a role-based system, meaning each user sees only the features relevant to their assigned role. The platform is hosted at alumni.wedev.com.ng and is accessible from any device with a web browser.

Key capabilities of the system include:

  • Member registration, login, and profile management
  • Online and offline membership fee payment
  • Automatic Membership ID generation upon payment
  • Digital ID card with QR code verification
  • Community tools: forum, announcements, events, committees
  • Full elections workflow — from applications to voting to results
  • Donation campaigns for members and projects
  • Admin panel for complete system management
  • Financial reporting and payment audit trail
  • Birthday celebration feature on the home page

2. User Roles

The system has four distinct roles. Each role has a specific set of permissions and sees a tailored interface.

Role Description Access Level
Member Standard registered alumni. Can pay dues, view their ID card, participate in elections, join the forum, donate, and manage their profile. Member area only
Admin Full system access. Manages all users, settings, content, payments, elections, committees, and reports. All areas + Admin Panel
Financial Secretary Manages payment verification and financial reporting. Approves or rejects offline payments and exports financial data. Member area + Finance Panel
NEC Member National Executive Committee member. Manages elections — creates positions, reviews applications, announces candidates, and views results. Member area + NEC Panel
Note: A user can only hold one role at a time. Roles are assigned by the Admin from the User Management panel.

3. Getting Started

3.1 Registration

  1. Visit the homepage at alumni.wedev.com.ng and click Register
  2. Fill in your personal details: First Name, Last Name, Email, Phone, State, Department, Graduation Year, and Password
  3. Accept the Terms & Conditions
  4. Click Submit — a welcome email is sent to your email address
  5. Your account is created with Member role and pending membership status

3.2 First Login & 2FA

  1. Go to Login and enter your email and password
  2. If Two-Factor Authentication (2FA) is enabled on your account, a 6-digit OTP is sent to your email
  3. Enter the OTP on the verification screen (expires in 10 minutes)
  4. You are redirected to your member dashboard
Security: After 5 failed login attempts, your account is temporarily locked for 15 minutes. Contact the admin if you are locked out.

3.3 Paying for Membership

  1. From your dashboard, click Pay Dues
  2. Choose a payment method:
    • Paystack — pay online with debit card or bank transfer. Membership is activated instantly on payment.
    • Bank Transfer — transfer to the organisation's bank account and upload your payment receipt. Membership is activated after the Financial Secretary or Admin approves the receipt.
  3. On activation, your unique Membership ID is generated and displayed on your ID card

4. Member Features

The following features are available to all logged-in members (regardless of role).

4.1 Dashboard

The member dashboard is the main landing page after login. It displays:

  • Membership status card: Active, Pending, or Expired — with days remaining
  • Quick navigation grid to all key sections
  • Active election alerts — positions open for application or voting
  • Profile completeness percentage with a list of missing fields
  • 2FA security toggle (enable/disable)
  • Recent donation history

4.2 Profile Management

Members can update their profile from Profile in the account sidebar. The following can be managed:

4.3 Membership ID Card

Active members can view and print their digital membership ID card from My ID Card. The card follows the ISO/IEC 7810 ID-1 standard (credit card size: 85.6 × 54 mm).

Front of card includes:

  • Organisation logo and name
  • Member's circular passport photo
  • Full name, job role
  • Membership ID, email, department, phone
  • Member's signature
  • Membership validity period

Back of card includes:

  • QR code — links to the member's public profile page
  • Organisation logo and name
  • Back content text (set by admin)
  • President's signature

The card is printable on A4 portrait paper. Anyone who scans the QR code can view the member's public profile (name, membership ID, department, job role, validity) without needing to log in.

4.4 Member Directory

  • Browse all active members
  • Search by name or department
  • Filter by state or graduation year
  • 18 members per page with pagination
  • Each card shows: name, photo, department, state, membership ID, job role

4.5 Announcements (Notices)

  • View all published announcements from the administration
  • Colour-coded priority levels: Normal, Important, Urgent
  • Announcements may have scheduled publish dates and expiry dates

4.6 Events

  • View all upcoming and past events
  • RSVP to events (where the admin has enabled RSVP)
  • See event location, date, time, and current RSVP count
  • RSVP capacity limits are enforced

4.7 Forum

  • Browse discussion categories created by the admin
  • Create new topics within a category
  • Reply to existing topics
  • Like or unlike posts
  • Delete your own posts

4.8 Elections

Members can participate in the full election process:

  • Apply for a position by submitting a manifesto (during the application window)
  • Track application status: Pending / Approved / Rejected
  • Vote for a candidate (during the voting window) — one vote per position
  • View approved candidates and their manifestos
  • See vote counts after voting ends
Important: Only active members with a valid, paid, non-expired membership can apply for positions or cast votes.

Each election position passes through the following states:

StateMeaning
UpcomingApplication window has not yet opened
Apply NowMembers can submit their candidacy
Under ReviewApplications closed; NEC is reviewing
Candidates AnnouncedApproved candidates are publicly visible
Vote NowVoting window is open
Election EndedVoting closed; results are visible

4.9 Committees

  • View all active committees and their member rosters
  • See each committee's purpose, duration, and chair contact
  • Download committee reports and documents

4.10 Donations

  • Browse active fundraising campaigns
  • View campaign progress bars (amount raised vs. target)
  • Donate online via Paystack
  • Option to donate anonymously
  • See campaign deadlines and days remaining

4.11 Payment History

  • View a full history of all your membership payment transactions
  • See payment status: Pending / Approved / Rejected
  • View reference numbers and dates

4.12 Birthday Celebrations

  • On a member's birthday, their profile card appears on the public home page
  • Visible to all website visitors — no login required
  • Shows: photo, name, job role, department, and a personalised congratulatory message
  • Members must set their Date of Birth in their profile to be included

5. Admin Features

The Admin has access to all member features plus the full Admin Panel at /admin/.

5.1 Admin Dashboard

Live statistics overview including:

  • Total registered users, active members, expired memberships
  • Pending payment approvals count
  • Total revenue collected
  • Active committees count
  • Recent payments table (10 latest)
  • Members by state (top 10 locations)
  • Revenue trend chart — last 6 months
  • New member signups chart — last 6 months

5.2 User Management

  • View, search, and paginate all registered users
  • Change any user's role: Member, Financial Secretary, Admin, NEC Member
  • Suspend a user — requires a reason; suspended users cannot log in
  • Unsuspend a user to restore access
  • Deactivate or reactivate accounts
  • View user profile details inline

5.3 Membership Management

  • View all memberships filtered by: All / Active / Pending / Expired
  • See each member's Membership ID, start date, expiry date, and days remaining
  • Summary count cards at the top of the page

5.4 Payment Management

  • View all payment records — online (Paystack) and offline (bank transfer)
  • Approve offline payments → automatically activates the member's membership and generates their Membership ID
  • Reject payments with optional notes
  • Resolve disputed payments via the Dispute Resolution tool
  • Manually upload corrected receipts
  • Email notification is sent to the member on approval

5.5 Financial Reports

  • Filter by date range
  • Total revenue breakdown: online vs. offline
  • Pending and rejected payment counts
  • Donation campaign revenue totals
  • Member expiry alerts (members expiring within 30 days)
  • Trigger manual stale-account cleanup

5.6 Announcements Management

  • Create announcements with title, body, and priority level (Normal / Important / Urgent)
  • Schedule a future publish date/time
  • Set expiry dates so announcements auto-expire
  • Delete announcements

5.7 Events Management

  • Create events with title, description, date, and location
  • Enable RSVP with optional capacity limit
  • Delete events

5.8 Forum Management

  • Create and manage discussion categories
  • Delete any post or topic (full moderation)
  • Pin important topics

5.9 Committee Management

  • Create committees with name, purpose, and start/end dates
  • Add members with roles: Chair, Vice-Chair, Secretary, or Member
  • Remove members from committees
  • Mark committees as Completed or Dissolved
  • Upload and delete committee reports (PDF/document)

5.10 Donation Campaign Management

  • Create campaigns with title, description, target amount, and deadline
  • Assign to a specific member (beneficiary) or a named project
  • Toggle donor name visibility (show/hide donors)
  • Close or archive campaigns
  • View all donation transactions per campaign

5.11 System Settings

See Section 8 for the complete settings reference.

5.12 Audit Log

  • Full trail of all system actions performed by all users
  • Search by action type, username, or description
  • Every entry shows: user, action type, description, IP address, timestamp
  • Colour-coded action badges
  • Paginated at 30 entries per page

5.13 Data Exports

  • Export Members CSV — all members with full details (name, email, phone, state, department, membership ID, dates)
  • Export Payments CSV — payment records filterable by date range and status

6. Financial Secretary Features

The Financial Secretary accesses the Finance Panel at /financial/ in addition to all standard member features.

6.1 Finance Dashboard

  • Total revenue collected to date
  • Pending payment approvals count (with alert)
  • Online (Paystack) vs. offline (bank transfer) payment split
  • Recent transactions table

6.2 Payment Verification

  • View all pending offline payment submissions with uploaded receipts
  • Approve — membership is activated immediately; member receives an email notification
  • Reject — recorded with optional notes visible to the member
  • Filter payments by status and date range

6.3 Dispute Resolution

  • Clear previously rejected payments
  • Upload corrected/replacement receipt
  • Manually activate membership for resolved cases

6.4 Financial Reports

Same reporting tools as the Admin — date-range filtered revenue breakdown, pending counts, rejection counts, and donation totals.

6.5 CSV Export

Export all payment records to a CSV file for use in Excel or accounting software.

7. NEC Member Features

NEC (National Executive Committee) members access the NEC Panel at /nec/ in addition to all standard member features.

7.1 NEC Dashboard

  • Total election positions created
  • Pending applications requiring review (alert)
  • Positions currently in the voting window
  • Total votes cast across all elections
  • Full positions table with state, applicant count, vote count, and dates

7.2 Election Position Management

  • Create new positions with: title, description, application dates, voting dates
  • Edit position details and dates at any time
  • Publish candidates — makes approved candidates visible to all members for voting
  • Delete positions (only if no votes have been cast)

7.3 Application Review

  • View all applications per position with applicant details and full manifesto
  • Approve an application — the applicant becomes a candidate
  • Reject an application — with optional reviewer notes
  • Filter applications by position
  • System validates that applicant still has an active membership at time of approval

7.4 Election Results

  • View vote counts per candidate for all ended elections
  • Identify the winner (highest vote count)
  • Notify winner — sends a congratulatory email to the winning candidate
  • Mark results as finalised

9. Security Features

FeatureDetail
Password HashingAll passwords are stored using Bcrypt hashing (cost factor 12) — never stored in plain text
CSRF ProtectionEvery form submission is validated with a unique CSRF token to prevent cross-site request forgery
Login Rate Limiting5 failed attempts per 15 minutes (per email address and IP address) — prevents brute force attacks
Two-Factor AuthenticationOptional email OTP — 6-digit code, expires in 10 minutes
Session SecuritySession ID is regenerated on login; cookies are HttpOnly to prevent JavaScript access
Password Reset TokensSecure tokenised reset links that expire after 1 hour and are single-use
File Upload ValidationMIME type is checked against the actual file content — not just the file extension
SQL Injection PreventionAll database queries use PDO prepared statements with bound parameters
Account SuspensionAdmins can lock accounts with a recorded reason and timestamp
Audit TrailEvery admin action is logged with the user ID, action type, description, IP address, and timestamp
Concurrency ProtectionDatabase transactions with SELECT FOR UPDATE locking prevent duplicate Membership IDs or double votes
Automatic Account CleanupPending accounts older than 7 days with no payment are automatically deleted (runs once per hour)
HTTPS EnforcementAll traffic is redirected to HTTPS automatically in production

10. Membership ID Format

Every activated member receives a unique Membership ID automatically generated on payment approval. The format is:

08 / TUN / XXX / 0001
SegmentExampleMeaning
0808Year code
TUNTUNOrganisation code
XXXLAG, ABJ, NAS3-letter code for the member's Nigerian state
00010001, 0042Sequential serial number — increments independently per state
Membership IDs are permanent, unique, and never reused. They are printed on the member's ID card and encoded in the QR code.
